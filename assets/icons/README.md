# Clickless icons

Selected mark: P7-8, optically recentered. The straight slash renders above an unchanged pointer.

- `source/clickless-app-icon.svg`: editable app-icon master.
- `source/clickless-tray-icon.svg`: transparent high-contrast tray master.
- `windows/clickless.ico`: 16-256 px Windows icon.
- `macos/clickless.icns`: 16-1024 px macOS icon.
- `linux/hicolor/*/apps/clickless.png`: Linux hicolor icons.
- `tray/*`: transparent tray PNGs from 16-64 px.

The pointer path comes from Font Awesome Free 6.7.2 `arrow-pointer`, licensed CC BY 4.0. The SVG masters retain attribution comments.
